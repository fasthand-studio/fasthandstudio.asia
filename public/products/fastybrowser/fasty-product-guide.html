Fasty BrowserProduct overview

Overview

A small, fast, quiet browser.

Fasty is a Linux web browser written in Go. It uses the system’s WebKitGTK 6.0 with GTK 4 and libadwaita rather than bundling Chromium or Electron.

LinuxDocumented target platform
x86_64Published 1.1.1 assets

1.1.1Latest verified release
What Fasty is trying to do

Stay native

Use Linux browser and interface libraries directly, with a focused Go application managing tabs, settings, privacy, extensions, and local tools.

Stay local

Keep history, bookmarks, settings, sessions, passkeys, and authenticator data on the user’s machine. There is no account, sync service, or cloud backup.

Stay quiet

Sleep unused tabs, block common ads and trackers, and avoid telemetry, crash reporting, analytics, and remote configuration.

Stay useful

Include reader mode, find, downloads, PiP, extensions, passkeys, TOTP, and an opt-in agent interface for authorized testing.

Project maturity: Fasty is a young project. Site compatibility, extension APIs, passkeys, PiP, and package testing have documented limitations. Release notes report testing on Arch only.

Features

Useful, with clear boundaries.

FeatureStatusWhat to know
Tab sleepingImplementedIdle tabs unload their WebKit process. Default sleep is five minutes; audio tabs stay awake.
Built-in blockingImplementedUses EasyList, EasyPrivacy, and StevenBlack hosts. YouTube ad handling is best effort, not guaranteed.
Privacy controlsImplementedLocal data, private sessions, WebKit ITP, third-party-cookie rejection, clean links, and per-site permissions.
PasskeysLimitedES256 only. No attestation, autofill prompts, USB security keys, sync, or phone/browser import.
AuthenticatorLimitedEncrypted TOTP vault with optional PIN, import, and export. No HOTP, Steam codes, or QR scanning.
Picture in pictureSite dependentProtected or cross-origin video may not be capturable; fallback modes may use another view or move the page.
ExtensionsPartialWebExtension-style manager with store, direct URL, and local-file installation. Some APIs are unsupported.
Agent controlOpt-inLocal Unix-socket API, off by default. Page fetch, XHR, and sendBeacon only; mandatory secret redaction.
NVIDIA decodingExperimentalOff by default. Requires supported NVIDIA hardware and packages; changes the web-process sandbox.
Performance claims: project measurements come from a specified test machine. They are not universal guarantees, and this guide does not turn them into marketing benchmarks.

Fasty BrowserPrivacy & security
05
Privacy

Local first. Not “offline.”

Fasty is designed to keep browser data on your computer. Pages, search engines, extensions, and public filter-list downloads still use the network.

Stays on your device

  • History, bookmarks, settings, and sessions
  • Passkeys and authenticator vault data
  • Blocking rules and browser configuration

Not collected by Fasty

  • No account or cloud sync
  • No telemetry or analytics
  • No crash reporting
  • No remote configuration
Agent control: permission is the boundary
  • The socket is off by default and lives at $XDG_RUNTIME_DIR/fasty.sock with mode 0600.
  • Any process running as the same user can control tabs while it is enabled.
  • Interception covers page-script fetch, XHR, and sendBeacon—not navigations, images, CSS, or plain form posts.
  • Replies and exports pass through mandatory secret redaction.
  • Use only on sites you own or are allowed to test, with test accounts and careful scope.
Encrypted local storage: passkeys and authenticator secrets are encrypted. If libsecret is unavailable, Fasty uses a user-only key file instead of the system keyring.
Do not overclaim: Fasty does not promise to make no network requests. Its own documented network activity is limited to public filter-list downloads; the web pages and extensions you use have their own requests.

Fasty BrowserTechnology & license
06
Open source

Built on the Linux stack.

Fasty combines a Go application, native GTK interfaces, system WebKit, a Rust ad-blocking library, and optional native helpers.

Go applicationTabs, settings, privacy, extensions, agent API, and browser data. The module declares Go 1.27.4.
GTK 4 + libadwaitaNative desktop controls and adaptive interface patterns through gotk4 bindings.
WebKitGTK 6.0System web rendering and web-platform APIs. Fasty does not bundle Chromium or Electron.
Rust ad-blockingfasty-adblock uses Brave’s adblock-rust 0.13.6 with content-blocking support.

Fasty BrowserTroubleshooting & FAQ
07
Help

Start with the system.

Fasty will not start or a library is missing

Confirm WebKitGTK 6.0, GTK 4, libadwaita, libsoup 3, GObject Introspection, Graphene, the Vulkan loader, and GStreamer plugins are installed. Use the official installation guide for distribution-specific details.

H.264 video does not play

Install the GStreamer libav and “bad” plugins for your distribution. Fedora may require RPM Fusion and libavcodec-freeworld.

A site behaves differently than in Chromium

Fasty uses WebKitGTK, not Chromium. Some sites and browser APIs can behave differently. Check the project’s known-issues section and report a reproducible example.

An extension does not work

Extension compatibility is partial. Unsupported APIs can include captureVisibleTab and push subscriptions. Check the extension’s required APIs before treating it as a Fasty bug.

Picture in picture falls back to another view

Protected or cross-origin video may not be capturable. Fasty documents fallback modes that use another view or move the page.

Passkeys or authenticator import are unavailable

Passkeys are ES256-only, without USB security keys, sync, or phone/browser import. The authenticator supports TOTP, not HOTP, Steam codes, or QR scanning.

Can I install on Windows, macOS, or ARM64?

No such 1.1.1 asset is published, and the project does not document those platforms. Do not rename an x86_64 package or assume ARM64 compatibility.

How should I report a problem?

Use the official GitHub issue tracker. Include distribution, architecture, package format, GTK/WebKitGTK versions, installation method, and clear reproduction steps.
